# 猫源沉浸详情页

2026-10-22，按用户截图调整CatVodDetailPage，猫源和CatNode共用该详情路由。Emby详情页及首页分类tab不作调整。

- 全宽海报延伸至原生标题栏后方；标题居中，展示源实际提供的年份和更新信息。现有CatVodVideo未包含地区、演员字段，不填充猜测数据。
- 复用HomeHeroPalette取色与HomeHeroColors主题明度限制。参考Git提交09cbe0d中旧猫源首页Background的普通图片加纵向渐变叠层方式，移除DST_IN透明蒙版及离屏混合；不复制旧版500ms独立底色动画和压暗层。渐变全部节点使用heroSurface的RGB，从高度24%起经32段五次平滑曲线增加覆盖度，88%处完全覆盖，底部12%稳定为页面底色，避免在裁切边界才结束过渡。图片、渐变层使用相同的明确高度；Hero、详情头部、列表、导航和根节点显式使用同一个heroSurface。文字和播放按钮绘制在渐变层上方，保留原生材质。缺图、取色尚未完成或失败时显式回退当前主题底色；过期异步取色不得覆盖新作品或已失效的图片。
- 主播放区仅保留通栏“立即播放”胶囊，移除右侧选集／排序操作胶囊；标题栏仅保留返回，移除右侧作品信息与更多按钮，同时移除对应菜单、弹层及透明定位节点。
- 两列分集胶囊通过LazyForEach按行创建，单数末集保留半行宽度；当前集只改变文字颜色。按实际分集名称展示，超长集名使用原生Text跑马灯循环展示，每轮间隔1000ms、步长0.6vp并开启边缘渐隐；短名称保持静止，滚出可见范围暂停，播放等操作按钮不启用跑马灯。完整名称保留在无障碍文本。
- 线路使用原生Select；选集、播放胶囊使用ToggleType.Button承载组件级沉浸光感，复用DetailToggleButtonMaterialModifier，并读取设置页的厚度。旧系统或关闭系统材质时保留明暗主题的半透明底色与细边。
- 简介默认两行，可展开阅读。所有新增文案使用资源字符串，新增胶囊底色有明暗主题资源。

截图中的收藏、已看、下载不属于当前猫源已有能力，本轮不新增这些业务功能，也不放置无效入口。

## 播放与状态

播放继续经ProviderPlaybackLauncher及现有Provider实现。分集按源原始顺序展示，不修改原始episodes队列、分集ID或variantId；切换线路尽量保留同一集，否则选择该线路原始第一集。准备播放时禁止重复启动和切换线路。

读取本地播放历史恢复当前作品、当前可用线路中最近的分集；Provider继续管理实际续播进度。历史读取不阻塞详情首屏，过期历史不能覆盖用户刚切换的线路或分集。详情请求、取色都校验页面存活及请求代次；失败保留重试入口。
