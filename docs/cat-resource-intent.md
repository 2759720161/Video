# 多源资源点击意图与搜索衔接

2026-10-23，此前目录条目统一进入详情页。对于仅提供推荐索引的目录，其详情接口可能有意返回 `{}`；这类响应被通用作品解析器判为“该地址没有返回支持的作品列表”，导致点击推荐后无法继续找片。

## 分流规则

目录配置中的 `indexs: 1`（也接受 true 或字符串 "1"）作为当前已验证的推荐索引标记。来源名称或 key 不参与判断，也不将任意解析错误当成搜索指令。

1. 明确标记的推荐索引：保留目录的分类浏览能力，给作品附加搜索意图。点击首页海报或轮播直接进入搜索页，并带入实际作品名称，不请求该条目的详情或自动播放。缓存卡片缺少意图时，在导航前向本地运行宿主确认当前目录能力，避免先进入详情再立即替换搜索页。
2. 缓存条目若缺少意图字段：详情客户端仍会读取当前目录配置。确认推荐索引后，以专用异常通知详情页；有原始标题、且不是来自搜索结果时，替换为搜索页，避免多出无效详情层。
3. 未标记目录返回 `{}`：用独立的空详情状态提示“此条目暂未提供详情，可尝试搜索同名资源”，保留重试及“搜索同名资源”按钮，不自动跳转。
4. HTTP、网络、无效 JSON 和其他响应结构错误：保留真实错误及重试；有作品标题时可由用户主动搜索。
5. 有详情但没有播放线路：保留可读详情及原提示，增加搜索同名资源入口。

通用 `CatVodCodec` 的作品列表校验保持严格。详情、空详情和推荐索引在客户端边界区分，不通过放宽作品解析掩盖错误。

## 搜索模式与范围

搜索页先恢复已有模式、单目录选择和聚合范围，页面可见后于下一事件循环任务提交带入的关键词。自动搜索不依赖转场进度或额外渲染帧。推荐索引不作为播放资源搜索目录；若用户保存的是单目录模式，但当前目录不能搜索，保留关键词并提示选择目录。不会自动开启聚合，不会自动改为全部目录，不改写首页目录。

已保存的聚合子集照常生效；显式空范围或已失效范围保持阻止状态，不补为全选。未配置过搜索的用户沿用项目原本的默认行为。搜索结果继续展示实际来源和作品信息，用户自行确认匹配项，不自动选择同名条目或开始播放。

搜索页带入关键词仅提交一次。输入框回传与当前内容完全相同的文字不取消自动搜索；只有内容实际改变才视为编辑。手动提交会使排队的自动提交失效。页面隐藏后不发起待提交请求，尚未提交的关键词可在重新显示后继续；已经提交的搜索不会因回到前台而重复。搜索结果进入详情时标记来源，防止“详情→搜索→详情”自动循环；手动搜索入口仍保留。离页后的迟到响应不触发新导航，详情搜索按钮有重复点击保护，导航失败可重试。

## 缓存与兼容

目录能力和作品搜索意图纳入显示缓存，恢复图片时继续携带；旧缓存缺少字段按普通条目处理，由当前目录配置兜底。海报绑定标识包含搜索意图，避免图片和标题相同、点击行为变化后沿用旧回调。已有作品 ID、来源 ID、播放记录和配置中心入口保持原样。

没有按源的新旧区分协议，也不硬编码“豆瓣”目录名称。当前只解释已验证的 `indexs` 能力标记；未知格式不会猜测为搜索行为。

## 验证

桌面受限子进程运行同一份经校验的 LeeCatPaw 脚本，项目实际客户端成功读取五个分类和 30 部作品，取得 `indexOnly=true`、`searchOnly=true`，首页实际点击方法进入带同名关键词的搜索页，未发出详情 HTTP 请求，也未自动播放。

243 项相关回归测试通过，应用编译、打包和签名成功。一次采集接口测试遇到 Node fetch 拒绝操作系统随机分配端口（bad port），单独复核及完整相关回归重跑均通过，没有为此修改应用网络行为。

脚本运行仍仅允许读写独立临时目录；桌面 Permission Model 不支持 fsync 的限制仅由临时测试进程跳过文件 flush，应用无该替换。没有重新内置远端猫源脚本，没有自动安装或调试设备。搜索模式、范围、失败、取消和循环保护在本地回归中验证，手机交互仍需用户确认。
