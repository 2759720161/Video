# 继续播放卡片与退出帧

2026-10-23：猫源与Emby首页的继续观看栏按可用内容宽度排布为手机约两张卡片，间距12vp、最大宽度240vp，保持16:9封面和16vp圆角。标题压为一行，副标题保留一行；封面底部增加渐变衬底和“看到 00:17”观看位置，超过一小时显示时分秒。共享卡片的封面URL改变时重置图片加载状态；图片出错显示占位图。接着看不改变现有宽度，没有观看进度时不显示位置标签。

远程来源退出时直接获取视频Surface画面，不截取包含控件、弹幕或页面背景的整页截图。正常返回先取帧再导航，aboutToDisappear补充覆盖非返回按钮的离页路径，在停止播放器和释放会话之前调用；同一播放器页面对同一视频防重复。退出全屏但仍留在播放器、转入画中画继续播放、本地视频及无有效视频画面/进度时不走此远程截帧路径。本地视频继续使用LocalPlayerExtension已有的退出位置取帧逻辑。

ResumeFrameStore在第一个异步等待之前同步读取Surface，随后异步缩小、编码JPEG，最长边640px、质量82。API23及以上校正Surface旋转/翻转，低版本使用API15完整Surface读取。PixelMap和ImagePacker在finally释放，不为截图重建播放器或重新请求视频。读取失败时保留来源封面，不能据本地测试宣称已成功截取设备上的所有视频格式。

缓存位于应用私有filesDir/resume_frames，按SHA256(sourceId,mediaId)隔离，元数据仅含图片文件名、观看位置和保存时间，不保存播放URL或认证参数。新图片使用独立文件名避免图片缓存复用旧帧，元数据临时文件完成后重命名发布；同一作品较早完成的编码不能覆盖后来退出的帧。写入失败保留上一张，关闭文件句柄并移除临时文件，替换后移除旧图片；最多保留64条。读取时校验文件名、图片存在和观看位置差距不超过15秒；未命中继续使用来源封面。

猫源首页在既有历史刷新和图片代理重定位后优先取退出帧；Emby继续观看按相同来源/媒体ID读取。保存成功使用既有播放历史变更信号触发刷新，离页、旧来源代次和被新请求替换的异步查图结果不能覆盖当前页面；不修改来源原始海报、轮播、缓存快照或播放历史进度。继续观看下方的普通海报仍按上一需求排除轮播作品。

验证包含同步取帧先于停止、跨来源及分集隔离、进度不匹配回退、新封面URI、重新创建运行类后磁盘恢复、异步竞态、读取/编码/短写/重命名失败时保留原图、资源释放和64条清理上限，以及猫源和Emby历史异步刷新、播放器返回控制、卡片尺寸及时间格式。构建及签名包证据见tmp/continue-exit-frame-evidence.json。未自动安装或调试手机；Surface实际可读性、画面方向及设备显示仍待实机确认。

少量卡片对齐修正：Scroll的align默认为Alignment.Center，内容总宽小于视口时会居中。猫源继续观看、Emby继续观看/接着看、本地主页最近播放、Emby媒体库横向栏目均显式设置Alignment.TopStart，使一张或少量卡片从内容区域左侧开始；卡片多时仍按自然内容宽度横向滚动。不拉伸卡片或Row，不改动封面、进度、截帧和分页逻辑。构建与包校验记录见tmp/continue-left-align-evidence.json。
