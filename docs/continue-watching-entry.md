# 来源独立的继续播放入口

2026-10-24。

猫源首页的“继续观看”标题右侧显示 chevron_right 符号按钮，44vp 点击区域，图标靠近屏幕右边缘。入口复用已注册的 ContinueWatchingPage，携带 view=continue、sourceId、当前目录 spiderKey 和目录名称，重复点击不叠加路由。

列表按图片参考呈现横向记录：左侧 16:9 退出帧、观看时间和进度，右侧作品、分集及播放来源。退出帧缺失时保留来源封面；记录按最近观看排序，只列出当前来源未播完的记录，底部显示“已加载全部内容”。返回页面和观看历史变更时重新读取记录与退出帧。点击调用既有 ProviderPlaybackLauncher，传入原 sourceId、mediaId 和 positionMs，准备期间阻止重复点击并显示加载状态。

## 隔离规则

- 独立订阅、影视接口和 Emby 服务按 sourceId 隔离。当前入口不回退到混合的全来源列表。
- 同一 Cat Node 订阅的目录按作品 ID 内编码的 catnode:<目录 key>:<作品 ID> 隔离。CatNodeProvider 的首页卡片先按目录过滤，再应用数量限制，避免其他目录挤占条数。
- 旧的未编码目录身份只在订阅明确设置 legacySpiderKey 且匹配当前目录时归属该目录；不能确定归属的记录不随机放入每个目录，也不删除存储中的原记录。
- Emby 首页使用相同的箭头按钮，保持 EmbyLibraryPage 的 sourceId + view=resume 路由，从当前 Emby 服务读取续播，不与猫源记录合并。
- WebDAV 首页同样提供箭头，传入当前 WebDAV sourceId，记录与其他 WebDAV、猫源及 Emby 分开。
- 顶栏垃圾桶进入选择管理，删除仅处理当前列表中选中的具体记录。此入口没有跨来源清空操作。
- 原有完整“播放历史”入口保持原展示方式；新的 continue 模式独立于其历史汇总布局。

## 验证范围

业务测试覆盖路由防重入、来源/目录隔离、缺失范围时不混合、过滤后限制条数、旧身份归属、退出帧优先、原续播点传递、来源内选择删除。沿用原有播放地址缓存与来源解析链路。本次不自动安装或调试设备，未进行手机原生布局目视验证。
