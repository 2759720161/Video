# Cat 订阅

项目已取消固定猫源脚本内置。安装包保留 ARM64 Node 24.2.0 运行核心、宿主适配器和许可文件，用户通过 `index.js.md5` 地址添加订阅。应用没有默认订阅地址，也不会在未添加订阅时下载猫源程序。

## 添加与使用

服务 → ＋ → Cat 订阅。

新添加订阅默认选择返回目录中的第一项，不优先指定某个来源。已保存且仍有效的手动选择继续保留；原选择已不在目录中时也回退到第一项。

添加页参照提供的截图：顶部返回及保存按钮、可选名称、必填 `index.js.md5` 地址、首次启动说明，以及可选服务器图标。名称留空时使用“Cat 订阅”；图标可从图库选择，也可恢复默认。

顶部保存按钮与表单底部“下载并保存”使用同一保存流程。保存期间依次显示版本检查、脚本下载、脚本校验、核心启动和来源读取状态，操作完成前不能重复提交。地址不正确、网络失败或核心启动失败时，同时保留页面错误并显示即时提示，不会把失败的订阅写入服务列表。

保存时下载并校验脚本，启动核心并读取订阅目录，成功后才写入服务列表。首次保存可能需要较长时间。选中订阅作为首页来源后，左上角直接显示当前来源名称，点击名称旁的下拉箭头打开来源菜单。菜单不显示勾选标记，当前项使用蓝色字体。选择后保存来源设置并刷新首页，标题同步显示选择项。独立浏览页仍可通过来源面板搜索并切换。

猫源首页不再显示固定“首页”标题或内容区重复的来源切换栏，标题区域使用仅含名称和下拉箭头的圆角按钮，不显示文字左侧图标。来源菜单保留系统支持的沉浸材质，并适配浅色和深色主题；条目较多时菜单可滚动。分类横向排列。推荐页的继续观看使用横向卡片展示播放进度；影片使用随可用宽度调整列数的海报网格，海报底部显示更新状态。搜索结果提供清除入口，加载时显示占位卡片，分页失败可在列表底部重试并保留已有内容。

原有 JSON 采集方式保留在“猫源”入口。

## 首页轮播

猫源与 Emby 首页共用 `components/media/carousel/HomeMediaCarousel.ets` 的 3D 海报转盘：中间海报正面展示，两侧海报逐渐缩小、向内倾斜并略微下沉。滑动时姿态跟随实际位置连续变化；停稳后中间恢复正面。展示区域为 2:3，封面完整显示，比例不符时空余区域保持透明，直接透出首页背景。海报没有描边、外阴影、模糊填充或固定底板；仅在封面缺失或加载失败时显示占位符。

标题及真实年份／更新状态位于转盘下方，不随海报旋转；没有元数据时使用简介。点击侧边海报先将其移到中间，点击中间海报沿用现有作品详情入口，不添加图片文字遮罩。

相邻海报与指示条点击使用原生向前／向后一步，首尾互切也沿圆环相邻方向移动，避免绝对序号跳转跨越多张。非相邻指示条保留直接选择；首尾诊断与验证范围见 [轮播诊断记录](home-carousel-color-sync.md)。

圆角作用于按原图比例缩放后的图片本身，外层展示区域不再裁圆角。原图尺寸读取完成前不显示图片，避免先按默认比例裁切再跳变；横图、方图及较窄海报均保留完整内容。切换封面时重置尺寸状态，并忽略旧地址的加载回调。

姿态使用五次平滑插值，在中心、两侧及远端的连接处保持对位置的一阶、二阶导数连续。相邻海报倾斜参数为 24°、缩放参数为 86%，更远处逐渐过渡到 30°、82%；相邻透明度为 90%，远端为 78%。向两侧单调下沉 6 vp、后退 56 vp，远端延伸到下沉 8 vp、后退 72 vp，移除途中先上浮再下降的路径。自动轮播使用 720 毫秒缓入缓出曲线，手动归位保持 420 毫秒、点击切换使用 500 毫秒；降低点击启动斜率并平缓收尾，曲线不产生过冲。这些是动画输入参数，最终投影还受透视影响。

标题按海报位置先淡出再淡入，限制同时可见的范围以减少文字叠影；副标题在更靠近中央时才出现。标题位移改为同一平滑插值，停稳时归零，最大 6 vp。指示条连续缩放与变化透明度，保留 32 × 32 vp 点击区域，选择最近的循环显示槽，不打开详情。轮播显示列表在数据变化时重建，滑动每帧复用；姿态与文字变化不额外触发取色。

手动滑动或点击海报、指示条后暂停自动轮播，手势与切换动画结束后静置 3 秒，再允许原有 5 秒间隔的自动轮播继续。重复操作重新计时；离页、后台、不可见及换源时取消等待，旧定时回调不能改变新状态。图片解码且尺寸确定后以 180 毫秒透明度过渡出现，按压有轻微缩放反馈；显示尺寸与圆角不参与入场动画。

所有海报、标题和指示条共用一个连续视觉中心，由靠近中央的页面回调驱动。位置换算包含卡片间距，尚未收到回调的旁卡也持续运动，远处旧回调不会使进度倒退。选中项回调只更新业务选择，动画结束按最终偏移校准，手势中断时保留实际位置，避免先停顿再二次散开。仅换源或外部选择变化时重置视觉中心；换算依据见 [Emby 轮播文档](emby-home.md)。

轮播按来源返回顺序选取第一页最多 6 个有名称、标识和封面的作品，跳过重复项，不额外请求其他来源或填写虚构评分。缺少简介、年份或更新状态时隐藏对应文字；没有有效封面时隐藏整个轮播。封面加载失败显示占位图。

支持左右滑动，多张时每 5 秒自动切换，只有一张时居中静止且不显示指示条。按住卡片、切换标签、应用进入后台或轮播移出可见区域时暂停自动切换。点击轮播沿用现有作品详情入口，保留订阅与来源标识。搜索和分类页隐藏轮播；加载更多保留第一页轮播，刷新或切换来源后重新选择并回到第一张。

首页背景跟随当前轮播封面变色。读取 64 × 64 缩略图的 RGBA 像素，按透明度计算整图平均色、近黑占比和色系覆盖率；只有色系占比明显领先时才适度增强该色系，黑色占比越高则越降低色度，避免局部鲜艳区域主导整页背景。完全透明像素不参与，预乘透明度会还原；像素读取不可用时回退到 Effect Kit 的 `getMainColor()`，不再从候选中跳过近黑区域去挑鲜艳色。不为黑白封面虚构彩色。

代表色保留原有色彩，浅色模式按 42%、深色模式按 50% 与主题底色混合，并限制亮度，增强不同封面之间的色调差异。卡片周围、列表与首页外层共用同一底色，按轮播连续位置实时混色，不再叠加 500 毫秒背景动画；深浅色主题变化后重新混色，不重新下载封面。

海报宽度随可用空间调整，最大 260 vp，转盘区域最大 720 vp；导航标题使用主题文字色，位于转盘上方。图片和信息区各自布局，不添加局部矩形、径向暗罩或文字阴影。共享尺寸及姿态规则位于 `HomeCarouselLayout.ets` 和 `HomeCarouselMotion.ets`。少量作品使用独立显示槽实现连续循环，来源数据、指示条数量、作品标识和详情路由仍按真实作品处理。

卡片基础间距为 20 vp，相邻卡片横向收拢为海报宽度的 3.5%，更远处渐进到 6%，让主海报与侧卡保留更多空隙；主海报尺寸和居中位置不变。间距同时参与滑动进度换算，保持滑动与停稳时位置连续。

取色成功结果按封面地址缓存，最多保留 32 项，同一地址的并发请求共用任务，优先预取当前和左右相邻封面的颜色，再预取其余作品，最多三个工作任务并行。滑动每帧只混合缓存颜色，不下载图片；颜色晚到时按最新位置重算。没有可用颜色时回到默认背景；快速切图、来源刷新、离页或进入后台后，旧任务不能覆盖当前颜色。取色不影响现有作品加载和播放入口。

猫源嵌入首页时，颜色通过独立回调直接更新背景，不在滑动每帧重发来源目录和菜单。首次取色仍依赖图片网络请求。取色请求编号、总耗时和成功状态使用 `HomeHeroPalette` 日志记录，不包含图片地址或认证参数，内存缓存命中和逐帧混色不输出取色日志。诊断记录见 [轮播背景同步](home-carousel-color-sync.md)。

猫源与 Emby 首页共用轮播组件及取色、混色服务，各自保留来源选择、数据加载和点击行为，见 [Emby 首页轮播与背景](emby-home.md)。

## 下载、更新与缓存

- 只接受 HTTP 或 HTTPS 的 `index.js.md5` 地址。脚本地址移除路径末尾的 `.md5`，保留原查询参数。
- 校验文件支持 32 位十六进制 MD5，以及标准 `MD5  index.js` 格式。下载脚本最大 32 MiB。
- 使用下载得到的原始字节计算 MD5。校验成功后另外记录 SHA-256；执行前再次核验两种摘要。
- 文件存放在应用私有目录，按订阅地址分开保存程序与配置。不同订阅地址不会混用配置文件。
- 每次启动运行环境时检查远端 MD5；未变化则复用已校验缓存，变化则下载新脚本。编辑页再次保存也会检查更新。
- 新版本使用单独文件名，校验完成后原子替换清单。下载内容与 MD5 不符时保留之前的清单。
- 网络不通时可以使用经过重新校验的缓存；HTTP 错误、无效 MD5 和校验不符会明确报错。没有可用缓存时不能离线首次添加。

内置资源目录 `entry/src/main/resources/rawfile/catnode/` 仅保留 `bootstrap.cjs`、`host.cjs` 与 `NODE-LICENSE.txt`，不再包含 `index.cjs`。

2026-10-23 补充：宿主新增公开图片请求适配模块 `artwork.cjs`，用于按图片域名规则补充 Referer 等请求头，不包含任何猫源包。项目按接口、参数和图片协议能力进行多源适配，不以“新源／旧源”分类；见 [多源图片适配](cat-artwork-compatibility.md)。

## 来源与播放记录

同一订阅中的来源共用该订阅的配置。作品标识包含来源标识，避免不同来源恰好返回相同作品 ID 时混淆播放记录；切换来源后仍可从继续观看恢复原来源的作品。

旧版已经保存的完整猫源条目保留，需要在编辑页补充订阅地址。原有条目的来源标识会保留用于兼容已有记录，不会静默替用户填入地址。

## 运行范围

同一应用进程一次运行一个订阅。Node 在专用线程中执行，仍与播放器共享应用进程。停止完成后才允许再次启动。

当前不支持 WebAssembly、Node 内置 fetch、网页登录／嗅探与弹幕推送。普通 http／https 和脚本的 Axios 请求路径可以使用；依赖上述未支持能力的来源可能无法工作。运行核心不附带 npm、Corepack 或 Inspector。

本轮补充：代表色支持本地缓存（最多 128 项、24 小时过期），内存缓存仍为 32 项；相同作品及元数据不再重建轮播显示槽。新增下载分阶段与同步链路汇总日志，详见 [轮播背景同步诊断](home-carousel-color-sync.md)。

本轮色差修正：亮度保护改为整体提亮或压暗颜色，避免逐通道截断把不同色相压成相同灰色。代表色缓存继续使用，取色及同步日志补充 RGB，详见 [轮播背景同步诊断](home-carousel-color-sync.md)。

2026-10-22 补充相近色区分：同色系且背景色差过小的代表色会适度拉开明暗，结果按原始颜色稳定排序并缓存；滑动仍按连续位置混色，原始取色及本地缓存不变。实测日志样本与规则见 [轮播背景同步诊断](home-carousel-color-sync.md)。

2026-10-22 整图取色：代表色由整张缩略图的明暗、色系占比及透明度计算，黑灰主体不再被忽略。近黑占比高时降低背景色度。取色缓存升级为 v2，首次重新取色，之后继续复用缓存；详细截图抽样见 [轮播背景同步诊断](home-carousel-color-sync.md)。
