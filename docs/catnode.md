# Cat 订阅

项目已取消固定猫源脚本内置。安装包保留 ARM64 Node 24.2.0 运行核心、宿主适配器和许可文件，用户通过 `index.js.md5` 地址添加订阅。应用没有默认订阅地址，也不会在未添加订阅时下载猫源程序。

## 添加与使用

服务 → ＋ → Cat 订阅。

新添加订阅默认选择返回目录中的第一项，不优先指定某个来源。已保存且仍有效的手动选择继续保留；原选择已不在目录中时也回退到第一项。

添加页参照提供的截图：顶部返回及保存按钮、可选名称、必填 `index.js.md5` 地址、首次启动说明，以及可选服务器图标。名称留空时使用“Cat 订阅”；图标可从图库选择，也可恢复默认。

顶部保存按钮与表单底部“下载并保存”使用同一保存流程。保存期间依次显示版本检查、脚本下载、脚本校验、核心启动和来源读取状态，操作完成前不能重复提交。地址不正确、网络失败或核心启动失败时，同时保留页面错误并显示即时提示，不会把失败的订阅写入服务列表。

保存时下载并校验脚本，启动核心并读取订阅目录，成功后才写入服务列表。首次保存可能需要较长时间。选中订阅作为首页来源后，左上角直接显示当前来源名称，点击名称旁的下拉箭头打开来源菜单。菜单不显示勾选标记，当前项使用蓝色字体。选择后保存来源设置并刷新首页，标题同步显示选择项。独立浏览页仍可通过来源面板搜索并切换。

猫源首页不再显示固定“首页”标题或内容区重复的来源切换栏，标题区域使用仅含名称和下拉箭头的圆角按钮，不显示文字左侧图标。来源菜单保留系统支持的沉浸材质，并适配浅色和深色主题；条目较多时菜单可滚动。分类横向排列。推荐页的继续观看使用横向卡片展示播放进度；影片使用随可用宽度调整列数的海报网格，海报底部显示更新状态。搜索结果提供清除入口，加载时显示占位卡片，分页失败可在列表底部重试并保留已有内容。

原有 JSON 采集方式保留在“猫源”入口。

## 首页轮播

猫源作为首页服务时，推荐区域顶部参考 [Kazumi HeroBanner](https://github.com/2759720161/Kazumi/blob/main/entry/src/main/ets/components/recommend/HeroBanner.ets) 展示轮播：模糊封面背景渐变衔接页面，左侧为标题、简介和来源实际返回的年份／更新状态，右侧为独立圆角海报。手机和平板分别调整轮播高度和海报尺寸，底部使用长短条表示当前页。

轮播按来源返回顺序选取第一页最多 6 个有名称、标识和封面的作品，跳过重复项，不额外请求其他来源或填写虚构评分。缺少简介、年份或更新状态时隐藏对应文字；没有有效封面时隐藏整个轮播。封面加载失败显示占位图。

支持左右滑动，多张时每 5 秒自动切换，只有一张时保持静止。切换标签、应用进入后台或轮播移出可见区域时暂停自动切换。点击轮播沿用现有作品详情入口，保留订阅与来源标识。搜索和分类页隐藏轮播；加载更多保留第一页轮播，刷新或切换来源后重新选择并回到第一张。

首页背景跟随当前轮播封面变色。从 64 × 64 像素缩略图通过 Effect Kit 的 `ColorPicker.getTopProportionColors(5)` 读取主要色块，按占比优先选取具有明显色彩的区域，跳过透明、近黑和近白的候选；没有合适色块或区域分析失败时，回退到 `getMainColor()`。不为黑白封面虚构彩色。

代表色保留原有色彩，浅色模式按 42%、深色模式按 50% 与主题底色混合，并限制亮度，增强不同封面之间的色调差异。轮播底部、列表与首页外层共用同一底色，颜色过渡为 500 毫秒；深浅色主题变化后重新混色，不重新下载封面。

取色成功结果按封面地址缓存，最多保留 32 项，同一地址的并发请求共用任务，并预取下一张封面的颜色。取色失败或当前封面加载失败时回到默认背景；快速切图、来源刷新、离页或进入后台后，旧任务不能覆盖当前颜色。取色不影响现有作品加载和播放入口。

猫源与 Emby 首页共用取色和混色服务；Emby 保留原有大图轮播，仅接入背景联动，见 [Emby 首页背景](emby-home.md)。

## 下载、更新与缓存

- 只接受 HTTP 或 HTTPS 的 `index.js.md5` 地址。脚本地址移除路径末尾的 `.md5`，保留原查询参数。
- 校验文件支持 32 位十六进制 MD5，以及标准 `MD5  index.js` 格式。下载脚本最大 32 MiB。
- 使用下载得到的原始字节计算 MD5。校验成功后另外记录 SHA-256；执行前再次核验两种摘要。
- 文件存放在应用私有目录，按订阅地址分开保存程序与配置。不同订阅地址不会混用配置文件。
- 每次启动运行环境时检查远端 MD5；未变化则复用已校验缓存，变化则下载新脚本。编辑页再次保存也会检查更新。
- 新版本使用单独文件名，校验完成后原子替换清单。下载内容与 MD5 不符时保留之前的清单。
- 网络不通时可以使用经过重新校验的缓存；HTTP 错误、无效 MD5 和校验不符会明确报错。没有可用缓存时不能离线首次添加。

内置资源目录 `entry/src/main/resources/rawfile/catnode/` 仅保留 `bootstrap.cjs`、`host.cjs` 与 `NODE-LICENSE.txt`，不再包含 `index.cjs`。

## 来源与播放记录

同一订阅中的来源共用该订阅的配置。作品标识包含来源标识，避免不同来源恰好返回相同作品 ID 时混淆播放记录；切换来源后仍可从继续观看恢复原来源的作品。

旧版已经保存的完整猫源条目保留，需要在编辑页补充订阅地址。原有条目的来源标识会保留用于兼容已有记录，不会静默替用户填入地址。

## 运行范围

同一应用进程一次运行一个订阅。Node 在专用线程中执行，仍与播放器共享应用进程。停止完成后才允许再次启动。

当前不支持 WebAssembly、Node 内置 fetch、网页登录／嗅探与弹幕推送。普通 http／https 和脚本的 Axios 请求路径可以使用；依赖上述未支持能力的来源可能无法工作。运行核心不附带 npm、Corepack 或 Inspector。
