# 独立影视搜索页

2026-10-22：猫源与 Emby 首页右上角搜索统一进入 pages/home/SearchPage。猫源不再通过浏览页展示分类和首页影片来承担搜索；原 CatVodBrowserPage 保留给独立来源浏览，分类吸顶及其原搜索功能继续可用。

页面借鉴 [Kazumi 官方搜索界面](https://kazumi.app/docs/intro/screenshots/#搜索) 的顶部输入与结果工具区层级，以及 [影视 TV 手机版](https://github.com/FongMi/TV/blob/fongmi/app/src/mobile/res/layout/fragment_search.xml) 的搜索历史组织方式；代码为本项目自己的 ArkTS 实现。

## 页面与交互

- Cat订阅导航标题下固定128 vp搜索区域：48 vp搜索框、56 vp双胶囊控制区及留白。左侧胶囊是聚合搜索开关，右侧在开启时显示范围与已选数量，关闭时显示单目录选择。Emby和普通JSON猫源保留112 vp搜索区域。输入框位于HDS标题区域，沿用SearchTitleMaterialModifier和材质厚度设置；不支持原生材质时使用普通背景。
- 输入内容只更新草稿与本地历史匹配，点击搜索按钮或键盘搜索才发起请求。提交时规范首尾和连续空白，空白词不请求；同一个待完成关键词的重复提交不会重复启动查询。更换草稿会清除旧结果并隔离旧响应。
- 搜索前展示当前范围的历史词条，可点击重搜；管理模式提供单条删除和清空。没有历史时展示简洁引导，不填充虚构热搜。
- 结果区显示“已加载”数量，提供默认顺序、按名称、按年份三种本地排序，以及海报网格／信息列表切换。默认顺序保留来源返回顺序；排序只针对已加载结果，不宣称源端全量排序。不存在的评分、年份、简介不虚构。
- 网格根据实际容器宽度自动使用 2–6 列，最大展示宽度 1200 vp；最后一列不追加右侧间距。标题最多两行。信息列表显示封面、标题、实际元数据、简介和来源名称。
- 查询时展示六张静态占位卡片；首次失败提供重试，空结果提供换词提示。猫源后续页失败保留已有结果与页码，支持重试同一页，不把局部失败替换成整屏错误。

## 搜索范围与作品标识

MediaSearchSession只连接打开页面时指定的服务。Cat订阅使用明确的聚合开关，不再将聚合模式混在单目录菜单里。开启时按已选目录聚合；关闭时恢复最后使用的单目录。没有保存过搜索模式时默认聚合，已有选择继续保留；最后的单目录独立保存，聚合状态下重新进入页面后仍可切回。普通JSON猫源和Emby继续搜索当前服务，不跨服务聚合，不显示聚合开关。

### 开关与范围面板

当前样式为悬浮双胶囊，去除整行底板。两枚胶囊各高48 vp、圆角24 vp，间隔10 vp，控制区高度仍为56 vp；平板上总宽限制为520 vp并靠左，避免两个胶囊被拉得过宽。左侧单行显示“聚合搜索”与原生开关，标题可点击切换，开关保留滑动及44 vp高的触摸热区。右侧聚合时显示“范围 · n”和箭头，关闭时显示单目录名称和下拉箭头。过长名称省略，无障碍描述保留完整目录和计数；窄屏左侧标题简化为“聚合”。

两枚胶囊位于HDS标题bottomBuilder，复用DetailTitleButtonMaterialModifier接入原生沉浸材质，跟随材质厚度设置；不支持时使用主题背景。左侧材质底板不接收触摸且不参与无障碍，前景标题与原生开关独立处理操作；右侧按钮保留交互形变、点光源及轻按反馈。聚合开启时点击范围胶囊打开大尺寸原生Sheet；目录列表单独滚动，顶部标题、名称筛选、已选数量和全选／清空保持可见，取消／应用固定在底部并留出安全区。

单目录菜单改为受控显示，绑定在右侧胶囊外层稳定的48 vp布局容器，避免使用点击位置或材质按钮的按压形变作为弹出基准；独立配置为下方右对齐、间隔6 vp、同窗口弹出，不再复用排序菜单参数。API26及支持设备限制菜单最大高度320 vp，超出部分滚动，屏幕不足时仍由系统避让。选中目录、切换聚合、重新初始化和离页均关闭菜单；遮罩点击关闭后同步清理显示状态。新增菜单显示守卫及关闭生命周期测试；未做设备坐标或视觉验证。

目录菜单与首页左上角猫源目录、右上角服务切换菜单统一使用SourceSelectionMenu及buildSourceSelectionMenuOptions。宽度由固定260 vp改为统一的内容自适应：通过当前UIContext的MeasureUtils测量各项16号Medium字体的单行宽度，转换为vp后预留64 vp菜单／文字内边距，普通菜单最小176 vp，最长不超过360 vp及窗口宽度的约78%，同时保留左右至少16 vp空间。窄于208 vp的窗口优先服从可用空间，不强制最小宽度。所有项按同一字重测量，避免选中项变化引起菜单宽度跳动；测量失败按文字长度保守回退。当前窗口宽度由EntryAbility独立维护menuViewportWidthVp，并随windowSizeChange更新，不使用物理屏幕短边作为分屏菜单上限。

共享24 vp圆角、16号文字与两行省略；选中项使用主题蓝色中等字重，不显示勾选图标。菜单项之间使用0.5 vp分隔线，左右缩进16 vp，颜色跟随主题。API26及系统支持时设置scrollBar为Off并保留320 vp最大高度，长菜单仍可滚动；旧系统保留原生滚动条策略。各入口保留自己的锚点方向和选择／关闭逻辑，服务菜单右侧锚点同步改用实际窗口宽度，搜索排序菜单不受影响。未自动安装或调试设备，原生菜单最终尺寸与位置仍需设备确认。

范围编辑使用草稿：筛选不会丢失被隐藏的已选项；全选／清空作用于全部可搜索目录；取消、关闭或下拉退出不应用草稿。至少选一个目录才能应用。保存成功后更新已选数量；如果正在聚合搜索，取消旧任务并按当前关键词、新范围重新搜索。保存失败保留原范围与草稿，面板显示重试提示；重复应用和保存期间的模式切换被拦截。

范围以media_search_aggregate_scope_v1:sourceId保存，按目录稳定标识记录，多个订阅独立。首次没有记录时默认全选；明确保存的子集不会自动纳入后来新增的目录。过期或禁用的目录被过滤，如果没有剩余项，提示重新选择，不能把空范围解释为全选。聚合范围与单目录各自保留，开关切换不改首页目录和订阅配置。

### 聚合搜索

- MediaSearchAggregate 每轮为每个待搜索目录请求一页，最多四个目录同时进行；单目录本轮等待上限12秒，超时记为失败。结果逐批合并到页面，显示本轮目录进度、失败或超时数、不支持搜索数，可以随时停止。
- 海报网格增加来源名，信息列表沿用来源展示。按完整命名空间作品ID去重，同名作品、不同目录相同原始ID分别保留；点击仍进入实际目录的详情与播放链路。
- “继续搜索”为还有后续页的目录各请求下一页；存在失败时按钮为“重试并继续搜索”，失败目录重试原页，成功目录不倒退，空对象目录不在后续轮次反复请求。部分失败不清空已找到的结果。
- 停止、换词、换目录或离页时取消当前调度，终止本轮专用客户端正在等待的HTTP请求，不再派发排队目录；晚到结果不写回页面。取消不关闭共享Node核心，脚本内部已发出的上游请求是否停止取决于脚本自身，不能以本地HTTP取消保证。
- 为避免大量结果一次创建过多海报，先显示60条，“展开更多结果”每次再显示60条；已加载数量及本地排序仍作用于全部已取得的结果，不丢弃后续条目。
- 聚合历史使用单独范围键，保留单目录的原历史，切回聚合后恢复自己的记录。模式、最后单目录和聚合范围分别保存，不修改订阅或首页目录。

猫源调用当前搜索目录客户端的 page('', keyword, page)，保留客户端返回的原始／命名空间作品 ID。目录切换创建独立客户端，既有作品的详情与播放仍按命名空间中的真实目录路由。请求下一页时验证来源返回页码，按作品 ID 去重合并，避免同名作品被错误合并。详情仍通过原 CatVodDetailPage 接收 sourceId 与 videoId。

### 豆瓣目录搜索不可用的修复

15:09:53–15:09:55 的 log.txt 显示提交事件和本地 HTTP 200 请求，但没有响应正文，不能仅凭 51 字节判断错误内容。用户确认当前目录为“豆瓣|首页”。重新下载所给订阅，脚本 MD5 与版本文件一致（35dcc10d533153dbb94298792664ad04）。该包 douban 的 search 实现为直接返回空对象，目录配置却标为 searchable=1；桌面受限进程调用也得到 HTTP 200、正文 {}。

客户端将空对象识别为“当前目录未提供搜索功能”，页面引导使用搜索范围菜单切换目录；合法的 list:[] 仍作为普通无结果，其他格式或网络错误不误报为目录不支持。菜单排除配置明确关闭 searchable 的目录（0、字符串0、false）。不按目录名称硬编码搜索功能，也不改动下载的猫源脚本。

新增 MediaSearch 汇总日志：初始化失败、请求开始、成功页数与条数、失败类型。不记录关键词、订阅地址、认证参数或原始响应。

Emby 调用原有 searchRaw，保留原 EmbyItem 和 imageUrlFor(item, 360) 的同一图片地址。SearchResultCard 为每个实际卡片实例生成共享转场标识；点击时把原条目、转场标识和同一图片地址传给 buildEmbyDetailRouteParams，保留剧集／季的详情归并行为。图片回调核对原地址，旧图失败不能覆盖新图状态。

Emby 搜索仍沿用现有客户端的一批结果能力；单目录猫源返回有效 pagecount 时展示加载更多，聚合模式分别跟踪各目录页码。结果数量标记“已加载”，不当作全量命中总数。

## 历史与请求隔离

历史使用 media_search_history_v1:sourceId:siteKey 范围键，分量经过编码，最多保留20个唯一关键词。聚合范围使用编码后的保留键 /aggregate，该值包含普通目录标识不允许出现的斜杠。键不包含订阅地址或认证参数。Emby 新范围没有记录时，从原 emby_search_history 迁入一次；已清空并保存为 [] 的范围不会重新导入旧记录，猫源不导入 Emby 的历史。

写入使用 PreferencesStore 的严格串行写入，并在进入异步操作前捕获范围键和内容快照。保存失败给出提示，不影响已取得的结果。初始化和搜索分别使用代次隔离；换词、重试初始化、离页或会话变化后，旧结果、旧错误和旧忙碌状态不能覆盖当前页面。聚合请求使用独立取消控制器销毁本地HTTP请求；原单目录和Emby仍通过代次隔离写入。
