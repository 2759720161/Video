# Emby 首页背景跟随轮播

保留 Emby 原有的大图轮播，包括图片布局、精选推荐文字、尺寸、5 秒切换周期、底部指示条和点击播放行为。继续观看、接着看、资料库栏目和观看进度恢复入口沿用原来的流程。

当前轮播图的代表色用于轮播底部、首页内容区和首页外层背景，以 500 毫秒过渡衔接。背景取色使用轮播实际显示的图片地址：优先背景图，其次缩略图、主海报；不改写 Emby 生成的图片地址及认证参数。

取色与混色逻辑由猫源和 Emby 共用，位于 `services/media/HomeHeroPalette.ets` 和 `HomeHeroColors.ets`。从主要色块优先选取有效色彩，浅色模式混色比例为 42%，深色为 50%，并限制亮度。结果按图片地址缓存，最多 32 项；相同地址的并发请求共用任务，预取下一张轮播图的颜色。深浅色主题改变时重新混色，不重新下载图片。

推荐列表分批更新时，当前作品仍存在则保留当前轮播项，否则回到第一项。搜索结果、空列表、错误状态或当前图片加载失败时恢复默认背景。过期轮播请求、旧服务器及旧配置的颜色回调不能覆盖当前首页。

2026-10-21：140 项相关本地测试通过，编译、打包和签名通过。覆盖原轮播结构及交互、Emby 请求与详情路由、图片地址回退、背景联动、异步隔离、列表增量更新、主题变化，以及猫源的原有回归测试。图片、取色接口在本地测试中使用替身。按用户要求，未进行设备自动安装或调试，真机背景颜色及动效仍需目视确认。
