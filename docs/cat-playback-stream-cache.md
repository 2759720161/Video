# 猫源最终播放地址复用

2026-10-24。此功能补充此前仅保存作品详情、线路偏好和运行期准备状态的实现。

## 行为

CatNodeProvider 在准备实时详情和调用来源 play 之前，先查找本分集、线路对应的有效地址缓存。验证成功时使用缓存的 PlaybackStream，沿用已有元数据恢复当前作品、选集分组和续播点；有有效作品元数据时无需来源 init/detail/play。来源运行库本身仍需启动，以取得当前订阅与配置版本。元数据已过期或身份不匹配时沿用正常详情恢复和身份校验，不凭一个 URL 构造另一作品会话。

未命中、临近过期、验证失败或显式强制刷新时，回到原有来源准备与解析流程。成功解析的可复用地址会写入当前订阅私有目录的 playback-streams.json。缓存命中不重新写入或延长有效期。尚未成功解析过的资源没有缓存可用，本功能不能从空地址响应中生成媒体地址。

## 可复用地址

- 普通 HTTP/HTTPS 媒体地址及必要的请求头、Referer、User-Agent。
- 当前匹配完整结构的 pst 本地代理票据：解码后必须有独立的远程 url 和合法 headers。保存上游请求以及原始 /spider/.../proxy/... 相对路径和完整票据，不保存旧 localhost 端口。相对路径中的不透明标识只在完整票据存在、内容与上游请求匹配且当前运行期验证通过时使用，不能单独当作来源内存记录恢复。
- 依赖来源内存记录、没有完整上游请求的本地代理，以及 js2p、文件路径、额外代理设置不参与持久复用。不对这类 URL 盲目替换端口，不宣称所有源的代理协议都支持恢复。

恢复时优先把上述相对路径绑定到当前运行库端口，以保留来源代理处理及票据中的分块参数。必须先验证当前代理实际返回媒体；不接受任意外部代理基址，不把上游认证头或旧代理认证头发送给恢复的本地代理。代理验证失败才验证远程直连；两者失败则正常重新解析。该策略只适用于自包含票据，不能保证每种源代理都支持跨进程恢复。

此前版本只保存上游请求的条目仍可走直连验证，不凭空推导代理路由；要启用代理恢复，需要该资源重新成功解析并形成一条带完整代理信息的新缓存。普通直连来源保持直连，不套用某个网盘或源名称的特殊逻辑。

媒体最终是否稳定播放需要设备验证；缓存媒体报 401/403 或缓存资源报 404/410 时，仅触发当前媒体的一次强制刷新，恢复来源正常解析所返回的播放方式。

## 有效期与隔离

地址缓存键包含来源 ID/类型/配置/版本、作品身份、分集身份、线路，以及已校验脚本 SHA256 和 profile.json 的哈希。配置中心变动同时清空作品缓存和地址缓存；登录资料和脚本变化不能命中旧条目。无明文配置或媒体 ID 日志。

每个订阅最多 12 条、总计 512Ki 字符，原子替换、UTF-8 写入，短写不覆盖旧文件。存储故障只关闭复用，不阻止正常解析。时钟回拨、文件损坏、非法请求头、旧运行期端口均不可作为有效缓存读取。恢复代理路径必须是完整票据代理且与缓存上游 URL 和请求头匹配。清空/淘汰有修订号保护；旧运行库返回的地址不写入新运行库作用域。

来源显式 expiresAt/expireAt/expire_at/expires_at/expires 及 URL 中支持的 epoch 到期参数会用于限期，支持秒和毫秒。无法确定到期时间时最多缓存 15 分钟；明确有效期也最多保留 2 小时，提前 30 秒停止复用。没有把未知有效期或模型默认 0 当作永久有效。

## 验证请求和刷新

使用 GET Range: bytes=0-4095，响应上限 8192 字节，每条验证总截止 1500 毫秒。直连带上游认证请求头，完整票据代理由来源自行还原上游请求。代理失败后直连可能再用一条验证请求，总验证等待最多约 3 秒。只接受有媒体特征的成功响应，拒绝空数据、HTML/JSON 登录页和失败状态；不单凭 HEAD 成功或 HTTP 200 认定媒体有效。各条验证请求在成功、错误和超时路径均释放。

验证失败后删除该条缓存，执行正常解析，不在本次流程中再次拿回同一个失效地址。播放器的强制刷新在解析期间临时设置 bypassStreamCache，并在成功或异常后恢复原队列意图；正常队列、手动选线与原有有限备用线路规则保持生效。日志记录 stream_cache 的命中、transport=source_proxy/direct、代理验证失败、验证耗时及存储结果，不记录 URL、票据或请求头。

首页预热发现有效期内的地址缓存时，不提前进行昂贵的实时详情准备；实际点击仍验证地址。预热不解析播放地址、不创建播放器。
